= Demo Docs

This directory collects the consumer-facing planning and walkthrough material for the
demo repository.

== Structure

* `capabilities/`
  What the demo is meant to show and how much of it is already covered.
* `walkthroughs/`
  Concrete end-to-end examples built around curated demo slices.
* `reference/`
  Practical command, dataset, and pipeline lookup material.
