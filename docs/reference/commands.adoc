= Commands

This page collects the most relevant demo commands.

== Environment

Use local core checkout:

[source,bash]
----
make setup-lib-local
----

Switch back to PyPI:

[source,bash]
----
make setup-lib-pypi
----

== Product Slice

Run the curated product slice:

[source,bash]
----
make run PIPELINE=./pipelines/demo_product_business_slice.yaml
----

Run the derived product overview slice:

[source,bash]
----
make run PIPELINE=./pipelines/demo_product_overview.yaml
----

Run the intentionally failing validation slice:

[source,bash]
----
make run PIPELINE=./pipelines/demo_product_validation_failures.yaml
----

Verify named ranges on a freshly generated product workbook:

[source,bash]
----
.venv/bin/pytest tests/test_named_ranges_demo.py -q
----

Run the multi-header product slice:

[source,bash]
----
make run PIPELINE=./pipelines/demo_product_multiheader.yaml
----

Verify the grouped headers on a freshly generated workbook:

[source,bash]
----
.venv/bin/pytest tests/test_multiheader_demo.py -q
----

Verify the editable roundtrip path:

[source,bash]
----
.venv/bin/pytest tests/test_roundtrip_editing_demo.py -q
----

Read a workbook back to JSON through `sheets-run`:

[source,bash]
----
make run PIPELINE=./pipelines/demo_workbook_reimport.yaml \
  IN_PATH=./tmp/product_business_slice.xlsx \
  OUT_PATH=./tmp/product_business_slice_reimported
----

== Phase 4 Compact Multiaxis

Use the local core checkout first:

[source,bash]
----
make setup-lib-local
----

Expand a compact matrix into a sparse relation:

[source,bash]
----
make run PIPELINE=./pipelines/demo_phase4_compact_multiaxis_expand.yaml
----

Compare sparse and lossless roundtrip modes:

[source,bash]
----
make run PIPELINE=./pipelines/demo_phase4_compact_multiaxis_roundtrip.yaml
----

Write the workbook as XLSX:

[source,bash]
----
make run PIPELINE=./pipelines/demo_phase4_compact_multiaxis_workbook.yaml
----

Write the same workbook as ODS:

[source,bash]
----
make run PIPELINE=./pipelines/demo_phase4_compact_multiaxis_workbook.yaml \
  OUT_KIND=ods OUT_PATH=./tmp/phase4_compact_multiaxis.ods
----

Run the Phase 4 demo checks:

[source,bash]
----
.venv/bin/pytest tests/test_phase4_compact_multiaxis_demo.py -q
----

== Generic Demo Flows

Run a custom pipeline:

[source,bash]
----
make run PIPELINE=./pipelines/demo_foo.yaml
----

Legacy compatibility shims:

[source,bash]
----
make pack
make unpack
make roundtrip
----

Verification flow:

[source,bash]
----
make verify
----

Extraction flow:

[source,bash]
----
make extract
----
