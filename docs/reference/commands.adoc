= Commands

This page collects the most relevant demo commands.

== Environment

Use local core checkout:

[source,bash]
----
make setup-lib-local
----

Switch back to PyPI:

[source,bash]
----
make setup-lib-pypi
----

== Product Slice

Run the curated product slice:

[source,bash]
----
make run PIPELINE=./pipelines/demo_product_business_slice.yaml
----

Run the derived product overview slice:

[source,bash]
----
make run PIPELINE=./pipelines/demo_product_overview.yaml
----

Run the intentionally failing validation slice:

[source,bash]
----
make run PIPELINE=./pipelines/demo_product_validation_failures.yaml
----

Verify named ranges on the existing product workbook:

[source,bash]
----
.venv/bin/pytest tests/test_named_ranges_demo.py -q
----

Run the multi-header product slice:

[source,bash]
----
make run PIPELINE=./pipelines/demo_product_multiheader.yaml
----

Verify the grouped headers:

[source,bash]
----
.venv/bin/pytest tests/test_multiheader_demo.py -q
----

== Generic Demo Flows

Run a custom pipeline:

[source,bash]
----
make run PIPELINE=./pipelines/demo_foo.yaml
----

Pack all datasets under `data/` to workbooks:

[source,bash]
----
make pack
----

Unpack current-SHA workbooks back to JSON:

[source,bash]
----
make unpack
----

Run both:

[source,bash]
----
make roundtrip
----

Verification flow:

[source,bash]
----
make verify
----

Extraction flow:

[source,bash]
----
make extract
----
